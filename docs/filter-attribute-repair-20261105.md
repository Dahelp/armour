# Восстановление характеристик составных фильтров — 5 ноября 2026

Причина: старый XML-экспорт сохранял только название параметра, без группы.
Импорт искал первое совпадение `attribute_name`, поэтому одинаковые размеры
внешнего и внутреннего элементов попадали в общие характеристики. Ошибка
подтверждена сравнением боевых данных с `goods_attribute` старого сайта.

## Исправлено на боевом сайте

- У 36 комплектов восстановлено 215 привязок к группам «Внешний» и «Внутренний».
- Значения, количество строк и принадлежность товаров не изменялись.
- В справочнике у характеристики 77 исправлена ошибочная группа 73 на 3.
- Все 36 публичных карточек проверены: отображаются 240 исходных размеров
  в соответствующих разделах, включая ранее правильно привязанные размеры.
- Перед записью сохранены строки в таблицах
  `product_attribute_backup_filter_groups_20261105` и
  `attribute_backup_filter_groups_20261105`.
- Запись выполнена под блокировкой таблиц: `attribute` использует MyISAM,
  `product_attribute` — InnoDB.

План с точными изменениями: `resources/repairs/filter-attribute-groups-20261105.json`.
Применение: https://github.com/Dahelp/armour/actions/runs/42024922853

Импорт теперь учитывает XML-атрибут `group`. Повторяющиеся параметры без
групп отклоняются до создания товаров. Экспорт сохраняет название группы
и использует действительный ID товара вместо отсутствующего `prod_id`.
Выкладка: https://github.com/Dahelp/armour/actions/runs/42025046928

сгруппированная высота в старой базе не подтверждает наличие двух элементов.

## Проверки

Проверены разбор XML с одинаковыми названиями в разных группах, отказ при
неоднозначных данных, совместимость обычного одиночного фильтра, безопасность
импорта и синтаксис PHP. На изолированных локальных копиях InnoDB и MyISAM
проверены предварительный просмотр, применение, резервные копии и повторный
запуск без дополнительных изменений. Публичные страницы проверены скриптом
`bin/verify_filter_attribute_pages.php`.
